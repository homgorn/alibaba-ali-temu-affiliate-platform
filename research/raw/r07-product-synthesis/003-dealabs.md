## Platform Overview

Dealabs is a French/EU deal-sharing community (similar to Slickdeals in US, part of Pepper.com which owns HotUKDeals, MyDealz, Dealabs, Pepper.ru, etc.)

### Key Features
- **Community-submitted deals**: Users post deals they find
- **Voting system**: "Hot" / temperature rating by community
- **Comments & discussion**: Users discuss deal quality, authenticity
- **Categories**: All product categories + travel, services
- **Alerts**: "Créer une alerte" - create deal alerts
- **Prime/Retailer tags**: "[Prime]" tags for Amazon Prime deals

### Deal Format
Each deal shows:
- Title with retailer & key specs
- Price (often with original/strikethrough)
- Description with bullet points
- Community temperature (hot/warm/cold)
- Comments count
- Retailer link (affiliate)

### Monetization
- Affiliate links on "Poster" / retailer links
- Community-driven (not algorithmic)
- No subscription visible

### Limitations
- Human-curated only (no automated price tracking)
- No price history charts
- No landed cost calculation
- No counterfeit detection
- No cross-border shipping analysis
- France/EU focused (not global)
- No API or data export
- Deal quality varies by community vigilance
