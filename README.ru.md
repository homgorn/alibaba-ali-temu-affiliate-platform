# Alibaba / AliExpress / Temu — Платформа affiliate-аналитики

> **Дать человеку ответ, который он не получит из поисковика — и заработать на
> его решении.**

Static-first, LLM-дискаверимая affiliate-платформа: загрузка товаров через API
affiliate-сетей, честная история цен и расчёт реальной полной стоимости.

**Статус:** Фазы 0–2 завершены. **Фаза 3 (движок) завершена: 24 таблицы, 127
тестов, 5 возможностей проверены независимо** (F011 миграции, F012 загрузка
данных, F013 история цен, F014 поисковый API, F017 исключение опасных
категорий). Живое API всё ещё требует учётных данных.
**Главная метрика:** первая реальная комиссия.

---

## Чем это отличается

Большинство affiliate-контента — это ссылка с одним предложением вокруг. Здесь
всё наоборот:

| Принцип | Что это значит на практике |
|---|---|
| **Честная полная стоимость** | Товар + доставка + пошлина + НДС + срок доставки — и **явное** указание, что именно определить **не удалось**. Неизвестное показывается как неизвестное, никогда как ноль. |
| **Определение фальшивых скидок** | Отличаем настоящие −40% от цены, которую завысили на 30 дней, а потом «снизили» обратно до нормы. |
| **Невидим для всех** | Каждая страница отдаёт полный HTML с сервера. `.md`-зеркала, `llms.txt` и заголовки `Link:`, чтобы ИИ-поисковики могли читать нас дёшево. |
| **Часть категорий исключена** | Опасные категории (батареи, зарядки, СИЗ, детские товары) **исключены полностью**, а не просто помечены. Отказ в безопасности калечит человека. |
| **Никогда не выдумывать** | Непроверенные факты помечаются `UNVERIFIED` с указанием, что было предпринято. Честный пробел лучше уверенной догадки. |

### Почему «static-first» — это не вкусовое решение

LLM-краулеры нельзя считать способными исполнять JavaScript. Если контент
существует только после гидратации, его могут просто никогда не увидеть.
Проектирование «без JS» безопасно при **любой** гипотезе о поведении краулеров;
проектирование «JS отрисуется» не безопасно ни при какой. Проверено по
документации краулеров OpenAI и спецификации llms.txt v2 — см.
[`docs/wiki/50-strategy-traffic/LLM-DISCOVERABILITY.md`](docs/wiki/50-strategy-traffic/LLM-DISCOVERABILITY.md).

## Что показало исследование

| Находка | Уверенность |
|---|---|
| **AliExpress Affiliate API существует и полностью задокументирован** — 11 эндпоинтов, протокол TOP, подпись `hmac`/`md5`, шлюз `gw.api.taobao.com/router/rest` | 8/10 |
| **`ship_to_country` возвращает цену по налоговой политике страны назначения** — полная стоимость становится lookup'ом, а не моделированием таможни | 8/10 |
| **`hotproduct.download` — массовая выгрузка, включающая `promotion_link`** — готовые affiliate-ссылки | 8/10 |
| **У Temu нет публичного API** — обе страницы партнёров являются JS-заглушками. Модуль строиться не будет | 7/10 |
| **Amazon PA-API 5 объявлен устаревшим** и возвращает `AccessDenied`. Любой туториал до 2025 мёртв | 9/10 |
| **Affiliate у Alibaba.com B2B существует** (до 15%), но требует `TradeCompleted` и блокирует любую MMP-атрибуцию | 9/10 |
| **Cookie-окно 3 дня**, комиссия 0–9% номинально (до 90% на Hot Products) — главное ограничение всей стратегии трафика | 7/10 |

### Чего мы НЕ знаем

Говорим прямо, потому что догадка хуже признания:

- **EPC / CPC / конверсия** — источник недоступен. **Решение D-020 запрещает траты на трафик до фактического измерения.**
- Комиссионные ставки большинства affiliate-сетей.
- Точный объём квоты API и подходит ли некитайское юрлицо.
- Конкурентная ситуация в RU/CIS.

## Правила работы

Четыре жёстких правила в [`AGENTS.md`](AGENTS.md):

1. **R1 — Ничто не удаляется без двойного явного подтверждения.** Действует для
   каждого агента, скрипта и человека.
2. **R2 — Никогда не выдумывать.** Помечать `UNVERIFIED` и писать, что пытались.
3. **R3 — Спека раньше кода.** Нет реализации без утверждённой спецификации.
4. **R4 — Секретов в git.**

Только агент `verifier` может отметить фичу готовой — и только после реальной
проверки сквозного пути.

## Стек

| Слой | Выбор |
|---|---|
| Язык | TypeScript · Node 22 · pnpm |
| Фронтенд | Next.js, **static-first HTML**, `.md`-зеркала, llms.txt |
| Хостинг | Cloudflare Pages + Workers |
| База | SQLite в разработке, Postgres-совместимая схема, Postgres в проде |
| Поиск | Postgres full-text search |
| Форма | Монорепо, модульный монолит, один деплой |

**На машине разработки нет Docker**, поэтому SQLite — дефолт для разработки, а
схема остаётся Postgres-совместимой: архитектура, которую нельзя запустить
локально, нельзя и проверить локально.

## Тестирование

Восемь уровней (L0–L7), подробно в [`ROADMAP.md`](docs/roadmap/ROADMAP.md).

**L7 — самый важный здесь:** сборка падает, если основной контент страницы
отсутствует в отрендеренном сервером HTML. Требование «HTML-first» очень легко
нарушить незаметно при рефакторинге и невозможно заметить глазами.

## Агентная система

Семь агентов, у каждого каскад моделей и наследованные правила.

```bash
node scripts/agents-doctor.mjs              # предпроверка; блокирует запуск при ошибке
node scripts/dispatch.mjs --check r06       # что уцелело после падения?
```

Первый раунд исследования потерял 8 из 8 агентов из-за лимитов провайдера — без
какой-либо валидации и без фолбэка. Это и породило данную систему. Известное
ограничение: каскад моделей защищает от перегрузки конкретной модели, но **не**
от исчерпанной квоты аккаунта.
